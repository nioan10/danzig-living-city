# Состояние проекта на 26 сентября 2026

Версия 0.11.0. Разработка приостановлена после расширения статистики.

Работают автономные жители с намерениями, обучением и семейными связями; договоры, рынок труда, производственные цепочки, семейные гильдии, строительство и развитие зданий, управление бюджетом и налоги, кризисы и пользовательские события. Внешний ИИ отключён. В статистике доступны шесть тем графиков с сохранением истории и выбором периода.

Последняя полная проверка: `node tools/check.cjs full` — 216 тестов, 0 ошибок, включая длительные симуляции. Проверены графики в браузере, сохранение и загрузка существующего города.

Для продолжения нужен Node.js 22.16+ или 24+. Запуск: `node server.js`, затем http://127.0.0.1:4173/. На Windows также можно использовать `start.cmd`. Установка пакетов не требуется. Навигация по модулям и проверки описаны в [DEVELOPMENT.md](DEVELOPMENT.md).

Текущий город сохраняется в браузере для адреса http://127.0.0.1:4173/. Репозиторий содержит исходники, ресурсы и тесты; клонирование не переносит браузерное сохранение. Для проверок интерфейса используйте `/?demo=1`, чтобы не изменять основной город.
